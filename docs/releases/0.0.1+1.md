# Shame 0.0.1+1

The first public build of Shame: a small, fast Dart/Flutter IDE for macOS.

## Highlights

- **A real editor, built from scratch.** Rope-backed buffers with an undo
  tree, multi-cursor selections, tree-sitter highlighting, folding, bracket
  matching, indent guides, inlay hints and snippets.
- **Dart and Flutter language support.** Completion, hover, go to definition,
  references, rename, formatting, code actions, organize imports and live
  diagnostics through the Dart analysis server, plus DAP debugging.
- **Flutter workflow.** Run, hot reload, hot restart, device selection, an
  embedded iOS Simulator rail, a web preview, test runs, pub get and pub add.
  The welcome screen and command palette can now create a new Flutter project
  and open it in one step.
- **An agent rail that sees the editor.** Claude, Codex and OpenCode run with
  Ask, Plan, Edit and Auto modes. A local IDE bridge gives the agent the active
  file, selection, cursor, open tabs, diagnostics, terminal tail and preview
  URL, and lets it open a file for you. Threads are saved per workspace.
- **Git and review.** A Git panel with branches, staged and unstaged changes,
  commit and push; a unified or split diff with per-file accept/reject; blame;
  and a live "AI Changes" list for agent edits.
- **A terminal dock, command palette, quick open and project search.** The
  terminal is Alacritty-backed; the command palette and keymap are user
  configurable.
- **macOS native build.** One universal `.dmg` for Apple Silicon and Intel.

## Install

1. Download `Shame-0.0.1+1-macos-universal.dmg`.
2. Open it and drag **Shame** into **Applications**.
3. Optionally verify the download against the `.sha256` file published next to
   it:

   ```sh
   shasum -a 256 -c Shame-0.0.1+1-macos-universal.dmg.sha256
   ```

The build is ad-hoc signed and not notarized, so macOS may show an
"unidentified developer" warning on first launch. Right-click the app and choose
**Open**, or run:

```sh
xattr -dr com.apple.quarantine /Applications/Shame.app
```

## Requirements

macOS 13 or newer. Dart/Flutter features need the Flutter SDK on your `PATH`.

## Known limitations

- macOS is the only platform built and tested.
- The app is not notarized; public builds show Gatekeeper's first-launch
  warning unless they are signed with a Developer ID certificate.
- Large files are virtualised in the editor, but syntax parsing is disabled
  above 256 KB.

## Build metadata

`0.0.1+1` is the first build of the `0.0.1` line. The `+N` suffix is the build
number and increments by one for every release: `0.0.1+2`, `0.0.1+3`, and so
on.
