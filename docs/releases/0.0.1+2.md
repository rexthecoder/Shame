# Shame 0.0.1+2

Shame grows beyond Dart and Flutter: Python projects, Jupyter notebooks and
data files now have first-class support, and the agent rail and editor get a
round of polish.

## Highlights

- **Python support.** Python syntax highlighting, a language server and run
  commands, plus an AI panel rail for Python projects.
- **Jupyter notebooks.** Run `.ipynb` notebooks on a Jupyter Server. Cells open
  with a language hint even without a file path. Shame connects to Jupyter
  servers, not Colab runtimes; see the docs for why.
- **Data views.** CSV/TSV table and JSONL dataset views, and a JSONL record
  inspector.
- **Runs tab.** A Runs dock tab with run sessions the agent can read, and the
  ability to run any command in the project from the tab.
- **Agent workspace checkpointing.** Checkpoint the agent's workspace and view
  per-turn diffs.
- **Filtering, sorting and more languages.** Filtering and sorting support, plus
  multi-language tree-sitter highlighting.
- **Editor and agent polish.** Assorted improvements to the editor, diff view
  and agent rail.

## Install

1. Download `Shame-0.0.1+2-macos-universal.dmg`.
2. Open it and drag **Shame** into **Applications**.
3. Optionally verify the download against the `.sha256` file published next to
   it:

   ```sh
   shasum -a 256 -c Shame-0.0.1+2-macos-universal.dmg.sha256
   ```

The build is ad-hoc signed and not notarized, so macOS may show an
"unidentified developer" warning on first launch. Right-click the app and choose
**Open**, or run:

```sh
xattr -dr com.apple.quarantine /Applications/Shame.app
```

## Requirements

macOS 13 or newer. Dart/Flutter features need the Flutter SDK on your `PATH`;
Python and notebook features need a Python install and, for notebooks, a
running Jupyter Server.

## Known limitations

- macOS is the only platform built and tested.
- The app is not notarized; public builds show Gatekeeper's first-launch
  warning unless they are signed with a Developer ID certificate.
- Large files are virtualised in the editor, but syntax parsing is disabled
  above 256 KB.

## Build metadata

`0.0.1+2` is the second build of the `0.0.1` line. The `+N` suffix is the build
number and increments by one for every release.
